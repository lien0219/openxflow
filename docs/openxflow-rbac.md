# OpenXFlow 生产级 RBAC

OpenXFlow 的授权体系由以下能力组成：

- 用户与超级管理员账号；
- 系统角色和自定义角色；
- 全局、组织、工作区、项目和渠道作用域；
- 用户角色分配；
- 团队成员与团队批量角色；
- 用户、团队、公开资源共享；
- 有效权限查询；
- 授权审计记录；
- 渠道服务身份最小权限隔离。

## 生产环境必需配置

```env
LANGFLOW_AUTO_LOGIN=false
LANGFLOW_AUTHZ_ENABLED=true
LANGFLOW_AUTHZ_AUDIT_ENABLED=true
LANGFLOW_AUTHZ_SUPERUSER_BYPASS=true
LANGFLOW_ENABLE_SIGNUP=false
```

说明：

- `AUTO_LOGIN=true` 仅适合本地单用户开发。权限中心仍可打开用于检查配置，但页面会显示“生产配置未就绪”。
- `AUTHZ_ENABLED=true` 后，后端接口会执行真实授权判定；前端菜单和按钮隐藏不能替代后端授权。
- `AUTHZ_AUDIT_ENABLED=true` 后，允许、拒绝和所有者旁路决策会写入授权审计表。
- `AUTHZ_SUPERUSER_BYPASS=true` 保留平台超级管理员应急权限；旁路操作仍应被审计。
- 生产环境建议关闭公开注册，由超级管理员或企业身份源创建用户。

## 内置系统角色

| 角色 | 用途 |
| --- | --- |
| `platform_admin` | 平台级全部资源和 RBAC 管理 |
| `organization_admin` | 指定组织或工作区的资源、渠道和用户授权管理 |
| `channel_admin` | 指定渠道连接的管理、执行和审计 |
| `resource_editor` | 工作流、项目、知识库、变量和文件维护 |
| `viewer` | 只读并可执行已共享资源 |
| `auditor` | 只读资源元数据、渠道活动和审计记录 |
| `member` | 默认成员；仅依靠资源所有权或显式共享获得访问权 |

系统角色在服务启动时幂等初始化。旧用户会自动迁移：

- 活跃超级管理员获得自动全局 `platform_admin`；
- 活跃普通用户获得自动全局 `member`；
- 渠道服务身份不会获得默认角色，也不能加入 RBAC 团队；
- 超级管理员被降级后，系统只回收自动生成的 `platform_admin`，不会删除其他管理员手工分配的角色。

## 作用域

| 作用域 | `domain_type` | `domain_id` |
| --- | --- | --- |
| 全局 | `global` | 必须为空 |
| 组织 | `organization` | 组织 UUID |
| 工作区 | `workspace` | 工作区 UUID |
| 项目 | `project` | 项目 UUID |
| 渠道 | `channel` | 渠道连接 UUID |

作用域管理员只能在同一作用域内授权，并且不能把自己不具备的权限委托给其他用户。此限制由后端执行，不能通过直接调用 API 绕过。

## 团队角色

团队既可以作为资源共享对象，也可以批量授予作用域角色：

1. 创建团队；
2. 给团队添加成员；
3. 给团队绑定角色与作用域；
4. 系统将团队授权安全地物化为普通用户角色分配，使现有授权热路径无需额外联表；
5. 多个团队授予相同角色时使用引用计数，移除一个团队不会误删仍被另一个团队使用的授权；
6. 用户原有手工授权永远不会被团队授权清理逻辑误删；
7. 停用团队会暂停团队派生权限，重新启用后自动恢复；
8. 删除团队、成员或团队角色时会同步清理对应派生权限并刷新权限缓存。

## 权限中心

入口：`设置 → 权限管理`

功能包括：

- **概览**：查看强制执行、审计、自动登录、超级管理员旁路和生产就绪状态；
- **用户权限**：查看用户的直接角色、作用域和最终有效权限；
- **角色管理**：查看系统角色，超级管理员可维护自定义角色和继承关系；
- **团队管理**：维护团队、成员和团队角色；
- **资源共享**：维护用户、团队、公开和私有共享；
- **权限审计**：分页查询允许、拒绝和所有者旁路记录。

非超级管理员不会获得全平台用户目录。作用域管理员需要输入已知用户 UUID，并指定自己有权管理的作用域后查看或授权。

## 人工验收清单

### 平台超级管理员

- 能看到“权限管理”导航和全部六个模块；
- 能创建、编辑和删除自定义角色，但不能修改或删除系统角色；
- 能给普通用户分配全局或作用域角色；
- 不能停用、删除或撤销自己的最后超级管理员入口；
- 能创建团队、添加成员和团队角色；
- 能查看完整授权审计记录。

### 普通成员

- 默认只有 `member`；
- 看不到未授权的权限管理入口；
- 只能访问自己拥有或被共享的资源；
- 直接调用管理接口返回 `403` 或隐私保护型 `404`。

### 渠道管理员

- 只能进入自己具有 `rbac:read` 的权限中心；
- 不会看到全平台用户目录；
- 只能在指定渠道作用域内分配不超过自身权限的角色；
- 无法授予 `platform_admin` 或跨渠道角色；
- 只能查看指定渠道范围内的审计记录。

### 团队角色

- 成员加入团队后立即获得团队角色；
- 成员退出团队后派生角色被回收；
- 两个团队授予相同角色时，移除一个团队后权限仍保留；
- 已存在的手工角色不会被团队清理误删；
- 停用团队后派生权限失效，重新启用后恢复；
- 删除团队后不残留团队角色映射或派生授权。

### 安全和审计

- 修改角色、分配角色、团队成员、团队角色和资源共享均有审计记录；
- 拒绝访问记录可按用户、资源、操作和结果过滤；
- 未授权用户不能枚举团队成员、团队角色或其他用户权限；
- 渠道服务身份不是超级管理员、没有默认角色、不能加入团队。
