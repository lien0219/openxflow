# OpenXFlow 四渠道生产接入说明

本文说明 `feature/channel-gateway` 中飞书、Telegram、钉钉和企业微信的生产能力、接入模式与性能保护。

## 统一运行模型

四个平台统一使用：

- 一个渠道连接对应一个机器人或应用身份；
- 管理员配置共享工作流、知识库与默认路由；
- 群成员直接使用共享能力，不要求每个人注册 OpenXFlow；
- 需要个人资源时再绑定 OpenXFlow 用户；
- 同一群聊可选择成员隔离上下文或共享上下文；
- Webhook 先验签、去重、短事务落库，再执行工作流和发送回复。

## 平台能力

### 飞书

- 支持私聊、群聊、@机器人、卡片动作、图片和文件；
- 支持回复原消息与线程上下文；
- Tenant Access Token 缓存、单飞刷新及失效后一次重放；
- 处理中卡片可更新为最终答案；
- 超长回答按平台预算拆分发送。

### Telegram

- 支持私聊、群、超级群和频道；
- 支持 `message`、`edited_message`、`channel_post`、`edited_channel_post` 和 `callback_query`；
- 群回复会引用原消息，Forum Topic 会保留 `message_thread_id`；
- 健康检查同时读取机器人身份和 Webhook 状态；
- 支持自动设置和删除 Webhook；
- 超长回答自动分段，按钮回调不会直接截断成冲突值。

### 钉钉

- 默认使用 Stream 模式，无需公网回调；
- 支持签名 Webhook 兼容模式；
- 每个启用连接维护独立 Stream 客户端；
- Leader 锁避免多个进程重复建立连接；
- 断线指数退避重连，并记录连接、同步和重试指标；
- `sessionWebhook` 有效时优先原会话回复，过期后降级 OpenAPI 发送。

### 企业微信

企业微信提供两种互斥模式：

#### 智能机器人 API（`ai_bot`，推荐）

- 支持员工私聊和企业内部群聊；
- 使用 Token + EncodingAESKey 的加密 JSON 回调；
- 首次回调立即返回加密 `stream` 响应，工作流在后台执行；
- 企业微信轮询同一 stream id，完成后返回最终内容；
- 支持文本、图片和图文混合消息；
- 可选配置官方群机器人 Webhook，用于主动推送或超出回调窗口后的补充消息。

#### 企业自建应用（`webhook`）

- 支持员工与应用私聊；
- 使用 Corp ID、Corp Secret、Agent ID、Callback Token 和 EncodingAESKey；
- 回调会校验 Agent ID，防止消息被错误连接消费；
- 该模式不宣称任意企业微信群聊能力。群成员共享机器人应使用 `ai_bot`。

## HTTP 与文件性能

四个平台共用事件循环内的 HTTP 连接池：

- 复用 DNS、TCP 和 TLS 连接；
- 默认最大连接数 32；
- 默认最大 Keep-Alive 连接数 16；
- 动态下载 URL 按 Provider + Origin 隔离连接池；
- 钉钉和企业微信动态 URL 都执行主机白名单与私网地址校验。

文件下载采用流式限额：

1. 先检查 `Content-Length`；
2. 按块读取并累计字节；
3. 超限立即中止；
4. 下载完成后再进入文件扩展名、内容类型和安全扫描流程。

默认下载上限为 50 MiB，可通过环境变量修改：

```env
LANGFLOW_CHANNEL_MAX_DOWNLOAD_BYTES=52428800
```

连接级 `max_file_size_mb` 与全局下载上限会共同限制文件，实际使用较小值。

## 长消息规划

回答发送前经过统一消息规划器：

- Telegram：单段预算 3900 字符；
- 飞书：单段预算 12000 字符；
- 钉钉：单段预算 18000 字符；
- 企业微信：单段预算 1800 字符；
- 优先在段落、换行、句号和空格处拆分；
- 卡片按钮只放在最后一段，避免每段重复动作；
- 每段独立重试，前面已成功发送的段落不会被重复发送。

## SQLite 运行要求

SQLite 模式必须保持：

```env
LANGFLOW_WORKERS=1
```

OpenXFlow 会：

- 允许 WAL 下并发读取；
- 串行化写事务；
- 拒绝同任务嵌套写 Session；
- 阻止两个后端进程同时打开同一数据库文件；
- Webhook、执行记录和投递记录均使用短事务。

多进程、多实例或高吞吐生产部署仍建议使用 PostgreSQL。

## 人工验收清单

每个平台至少验证：

- 私聊文本；
- 群聊文本（企业微信使用 `ai_bot`）；
- @机器人与非 @ 消息策略；
- 两名以上成员同时提问；
- 图片与文档；
- 超长回答；
- 平台 Token 失效恢复；
- 重复回调；
- 工作流超时；
- 平台限流和 5xx；
- 服务重启后的恢复；
- 消息、投递、执行和审计记录是否完整。
